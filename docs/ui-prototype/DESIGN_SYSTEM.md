# S3 RLCD Deck 仪表界面设计系统

> 原型参考——生产实现应把这些决定重写为正式组件和 ViewModel，不要直接导入原型代码。

## 产品气质

S3 RLCD Deck 是一台本地优先的技术仪表，而不是通用云端控制台。选定的 C 方案应在局部故障下依然精确、可检查并保持冷静：

- 高密度展示运行数据，并提供清晰的逐层深入路径。
- 明确标记数据可信度：已验证、推断、已过期、不可用。
- 明确标记发送权：TX 未启用、USB TX、Web TX。
- 故障旁直接提供恢复动作：重试、诊断、回滚或 Setup。
- 在操作位置说明安全边界：本机回环暴露、设备信任、脱敏、密钥存储和破坏性操作范围。

## 仪表外壳

信息架构采用两个稳定层级：

1. 72 px 深色 Dock 表示首页、AI 采集、串口工作台、设备和系统五个产品领域。
2. 250 px 上下文侧栏只列出当前领域的任务，并在底部显示系统健康状态。

检查画布保持宽阔和高信息密度。宽度小于 920 px 时，Dock 与侧栏合并为一个抽屉式上下文菜单，任务层级不发生变化。

## 设计变量

| 角色 | 值 | 用途 |
| --- | --- | --- |
| Dock 石墨色 | `#17231F` | 稳定领域导航和技术代码面板 |
| 仪表纸白 | `#FBFAF6` | 卡片、表单和主要表面 |
| 工作台背景 | `#E7E5DF` | 工作区画布 |
| 深绿色 | `#215A50` | 主要操作、焦点和选中数据 |
| 信号黄色 | `#F0C75E` | 选中 Dock 领域和原型提示条 |
| 成功 | `#1D7453` | 健康状态及文字标签 |
| 警告 | `#86610B` | 过期、租约和暴露警告 |
| 危险 | `#AC3037` | 破坏性操作和可恢复错误 |
| 界面无衬线字体 | Fira Sans → 系统无衬线字体 | 界面文案 |

原型使用系统备用字体，因为生产静态资源不能依赖 CDN。生产版本可自托管选定的 Fira 字体。

## 组件规则

- 按钮和字段至少 42 px 高；移动端控件至少 44 px 高。
- 主要按钮使用深绿色填充；一个局部决策组只保留一个主要操作。
- 破坏性操作使用危险色，准确说明范围，要求输入或二次确认，并解释恢复方式。
- 状态绝不只依赖颜色，每个指示都必须包含文字。
- 表格放在可横向滚动的容器内，行操作靠近受影响的数据。
- 表单在字段附近显示帮助或错误文案。密钥只显示引用或遮盖值，不重新显示明文。
- 焦点环为 3 px 且绝不移除；键盘顺序与视觉顺序一致。
- 动效仅用于短反馈和骨架屏；`prefers-reduced-motion` 会禁用动效。

## 通用页面状态

每个管理界面必须支持：

| 状态 | 行为 |
| --- | --- |
| 加载中 | 保留预期页面和卡片结构，显示带标签的骨架屏 |
| 空状态 | 解释没有数据的原因，并提供最相关的创建或连接操作 |
| 局部错误 | 说明失败边界，保留未受影响的数据，并提供重试和诊断 |
| 已过期 | 保留最后有效时间与可信度，不把旧数据伪装为当前数据 |
| 不可用 | 隐藏未知数值，不使用 `0` 代替 |
| 成功 | 说明由哪个权威系统确认了更改 |

错误使用 `role="alert"`；非阻塞完成反馈使用礼貌通知区域。

## 界面专属约束

### Provider 与历史

- Provider 配置是结构化数据：方法、URL、Header、JSON 正文和声明式 JSONPath 映射。
- 绝不执行粘贴的 cURL、Shell、JavaScript 或插件代码。
- 远程端点必须使用 HTTPS；私有 HTTP 始终显示例外警告。
- 测试预览会脱敏密钥和标识符。
- 历史只包含规范化小时快照，并排除在备份之外。

### 串口

- 多个浏览器可以观察，但只有一个浏览器可以持有 Web TX 租约。
- 租约状态、剩余时间和 USB 拒绝行为靠近发送控件显示。
- 预设不能绕过发送权、暂停或会话边界。
- 当前会话下载与长期历史必须有明显区别。

### 设备、Setup 与更新

- Companion 缓存设置不能在离线 Deck 重连时覆盖设备。
- 设备自有配置只有在 Deck 确认后才显示成功。
- Wi-Fi 候选配置必须通过关联和 DHCP 验证后才能替换最后有效网络。
- 配对、Token 轮换和信任撤销是三个独立且明确的操作。
- OTA 要求签名、Hash 和板卡型号匹配；旧分区保留至新版本通过健康确认。

### 备份与诊断

- 导入是事务流程：解密、预览、选择模式、处理冲突、确认，然后提交。
- 密码错误、归档损坏或 Schema 不兼容时，不产生任何部分更改。
- 支持包展示准确的脱敏清单，绝不自动上传。

## Deck 400×300

- 只使用黑色和米白色，通过文字、边框、实色填充和斜纹表达状态，不依赖颜色。
- 固定顶部栏包含本地时间、校准温度、Wi-Fi 和当前 Companion。
- 可选字段缺失时折叠；未知数值绝不显示为 `0`。
- AI 页面始终显示 TX 未启用；串口页面突出显示发送权所有者。
- Deck 不显示串口正文、Prompt、回复、密钥或绝对路径。
- 即使没有其他 Provider，也保留配置提示页。
- 精确字形覆盖与裁切仍需实体设备快照测试。
